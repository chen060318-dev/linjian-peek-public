# LR 掌心窗星轨开屏 v0.3.9.4

第二版开屏完全移除雨珠、折射和雨痕，改为 Android 原生 Canvas 绘制的黑银星轨动画。

## 动画顺序

1. 暗色宇宙与星点渐显，放射线从中心生长。
2. 放射线逐步组织成七层星轨圆环与刻度；组合完成后，每层按独立速度和方向持续转动。
3. 双鱼座与天蝎座星点连线从两侧出现，并缓慢靠近、连接。
4. `0714` 以竖排形式逐字显现。
5. 文案“这浩瀚宇宙诞生的意义 / 只为出现在我的眼底”由微弱模糊过渡至清晰。
6. 动画约 5.2 秒，随后交叉淡入首页；播放中点击可提前进入。

本次只修改开屏表现层和版本信息，不改变 MCP、OAuth、后台轮询及远程命令逻辑。
