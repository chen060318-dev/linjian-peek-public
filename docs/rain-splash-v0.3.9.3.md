# LR 掌心窗雨幕开屏 v0.3.9.3

第一版开屏动画使用用户提供的雨景底图，并在 Android 原生 Canvas 中完成，不依赖网络资源或 WebView。

## 已实现

- 同源清晰、柔化双层底图；默认展示冷白浅蓝灰的柔化层。
- 清晰层只在前景水滴轮廓内显示，并带轻微位置偏移，形成局部折射。
- 少量随机水滴、自然不规则轮廓、缓慢滑落和断续雨痕。
- 水滴上侧高光、下侧暗影及细边缘，减轻贴图感。
- 雾白噪声渐退后显出底图，中文与英文导入语由模糊逐渐清晰。
- 动画约 4.3 秒，随后以 460 ms 交叉淡化进入首页；播放中点击可提前进入。

## 后续细化方向

- 雨痕对微小水点的真实擦除。
- 水滴碰撞、吸附和体积守恒合并。
- 根据设备性能调整水滴数量及刷新频率。
- 结合实机观感继续调整文字位置、透明度和折射强度。
